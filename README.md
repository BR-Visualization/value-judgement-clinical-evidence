## Installation

You can install the development version of valueJudgementCE from
[GitHub](https://github.com/) using the following methods:

### Recommended Installation

``` r
# Install using pak (recommended)
install.packages("pak")
pak::pak("BR-Visualization/value-judgement-clinical-evidence")
```

### Alternative Installation

``` r
# Install using remotes
install.packages("remotes")
remotes::install_github("BR-Visualization/value-judgement-clinical-evidence")
```

`dev/generate_publication_plots.R` writes the publication figures to
`inst/img/pub/`. The file numbers do not follow the manuscript figure
numbers, so use this table to find the file for each figure.

| Manuscript figure | File in `inst/img/pub/` | Function |
|----|----|----|
| Figure 1 – Value tree | Not generated by the package | – |
| Figure 2 – Dot-forest plot | `image01_dotforest` | `create_forest_dot_plot()` |
| Figure 3 – Trade-off plot | `image02_tradeoff` | `tradeoff_utility_plot()` |
| Figure 4 – Predicted scatter plot | `image04_scatter` | `scatter_plot(style = "publication")` |
| Figure 5 – Divergent stacked bar chart | `image05_divergent_stacked_barchart` | `divergent_stacked_barchart()` |
| Figure 6 – Cumulative excess plot | `image06_cumulative_excess` | `cumexcess_incidence_plot()` |
| Figure 7 – Value function types | `image07_value_function_types_comparison` | `compare_value_function_types()` |
| Figure 8 – MCDA comparison (Drug A) | `image08_barplot_mcda_comparison_drug_a` | `create_mcda_barplot_comparison()` |
| Figure 9 – MCDA waterfall | `image09_mcda_waterfall_all_drugs` | `create_mcda_waterfall()` |
| Figure 10 – MCDA benefit-risk map | `image10_mcda_benefit_risk_map` | `create_mcda_brmap()` |
| Figure 11 – MCDA tornado (Drug A) | `image11_tornado` | `mcda_tornado()` |
| Figure 12 – Weight sensitivity, Drugs A-D vs placebo | `image13_weight_sensitivity_drugs` | `mcda_weight_sensitivity(comparator_name = "Placebo")` |

Each figure is saved as `.tiff` (for submission) and `.png`. These files
are not used in the manuscript:

- `image03_correlogram` (`create_correlogram()`)
- `image12_weight_sensitivity`: Placebo vs Drug A in Study 1
- `image14_weight_sensitivity_treatments`: all active treatments on one
  chart

The Drug B-D versions of Figures 8 and 11, and the weight sensitivity
charts for the other criteria, are in `inst/img/other/`.

``` r
# Create both plots
stacked_bar_fig <- stacked_barchart(
  data = comp_outcome,
  chartcolors = colfun()$fig12_colors,
  ylabel = "Study Week"
)

divergent_stacked_bar_fig <- divergent_stacked_barchart(
  data = comp_outcome,
  chartcolors = colfun()$fig12_colors,
  favcat = c(
    "Benefit larger than threshold, with AE",
    "Benefit larger than threshold, w/o AE"
  ),
  unfavcat = c(
    "Withdrew",
    "Benefit less than threshold, w/o AE",
    "Benefit less than threshold, with AE"
  ),
  ylabel = "Study Week",
  fav_side = "left"
)

# Extract and combine with shared legend
stacked_bar_with_legend <- stacked_bar_fig + 
  labs(fill = "Outcome") +
  theme(legend.position = "top",
        legend.justification = "center",
        legend.box.just = "center",
        legend.title.align = 0.5) +
  guides(fill = guide_legend(nrow = 2, title.position = "top", title.hjust = 0.5))

g <- ggplotGrob(stacked_bar_with_legend)
legend <- g$grobs[[which(g$layout$name == "guide-box-top")]]

stacked_bar_no_legend <- stacked_bar_fig +
  theme(
    legend.position = "none",
    plot.background = element_rect(color = "black", fill = NA, linewidth = 0.5)
  )
divergent_stacked_bar_no_legend <- divergent_stacked_bar_fig +
  theme(
    legend.position = "none",
    plot.background = element_rect(color = "black", fill = NA, linewidth = 0.5)
  )

combined_plots <- plot_grid(stacked_bar_no_legend, divergent_stacked_bar_no_legend, ncol = 2)
plot_grid(legend, combined_plots, ncol = 1, rel_heights = c(0.2, 1))
```

## Figure - MCDA Weight Sensitivity Plot

<img src="man/figures/README-mcda_weight_sensitivity-1.png" alt="" width="100%" />

<details>

<summary>

Click to learn more
</summary>

**About This Plot**

- One-way sensitivity analysis on criterion weights, following Figures 6
  and 7 of [Angelis and Phillips
  (2021)](https://doi.org/10.1111/bcp.14425)
- The weight on one criterion (here Rare SAE) is varied from 0% to 100%;
  the other weights are rescaled proportionally so all weights still sum
  to 1
- Each line is a treatment’s overall weighted score; the red vertical
  line marks the current weight
- Open circles mark weights at which the preferred treatment changes
- This figure uses `shading = "hiview"`, which reproduces the shading in
  the article: the first band and every other band after it are shaded,
  and nothing is shaded when the preferred treatment never changes
- The default, `shading = "change"`, instead shades the weights at which
  a different treatment would be preferred than at the current weight,
  so the unshaded band around the red line shows how far the weight can
  move before the decision changes; `shading = "none"` turns shading off

``` r
# A single criterion, with shading as in Angelis and Phillips (2021)

  criteria = "Recurring AE"
```
